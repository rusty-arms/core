# 0007. No assets, a distinct name, and no money

- **Decision:** D7
- **Status:** Accepted
- **Date:** 2026-10-18
- **Source:** [research brief](../research/brief.md) §2 D7, §4 Trademark

## Context

The project wants to share as much as the law allows while avoiding the main triggers for enforcement (see the enforcement climate in the brief, §4).

## Decision

Publish source and binaries with no assets, under a distinct name (not the original game's name), and take no money.

## Consequences

- This removes the main triggers for enforcement.
- The project is called Rusty Arms. One factual compatibility line naming the original game is allowed in READMEs.
- The US mark for the original name is held by its rights holder; the UK register has not been checked.
